Implementar Redis en docker
===========================

docker run -d --name redis -p 6379:6379 --restart unless-stopped redis:alpine

Comandos útiles

Verificar Redis
docker exec -it redis redis-cli ping

ver logs
docker logs -f redis

Detener e Reiniciar Redis
docker stop redis
docker start redis


ver Red/Ip en docker
docker inspect -f "{{json .NetworkSettings.Networks}}" redis


Interfaz Web
==============
docker run -d --name redisinsight -p 5540:5540 -v redisinsight:/data redis/redisinsight:latest

http://localhost:5540


Levantar catalogo-service
=============================

docker build -t ventastech/catalogo-service:1.0 .

docker run -d --name catalogo-service -p 8081:8081 ventastech/catalogo-service:1.0

Ejecutar contenedor:
docker run -d --name catalogo-service ^
  -p 8081:8081 ^
  -e SPRING_DATA_REDIS_HOST=host.docker.internal ^
  -e SPRING_DATA_REDIS_PORT=6379 ^
  -e SPRING_DATASOURCE_URL="<url-jdbc con host.docker.internal>" ^
  -e SPRING_DATASOURCE_USERNAME=<usuario> ^
  -e SPRING_DATASOURCE_PASSWORD=<password> ^
  ventastech/catalogo-service:1.0
